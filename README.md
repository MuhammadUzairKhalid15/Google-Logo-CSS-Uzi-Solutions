# Google Logo — Pure CSS Recreation

A recreation of the Google "G" logo built entirely with CSS — no images, no SVGs, just border colors, `border-radius`, and pseudo-elements.

🔗 **Live Demo:** https://google-logo-uzi-solutions.netlify.app/
💻 **Repository:** https://github.com/MuhammadUzairKhalid15/Google-Logo-CSS-Uzi-Solutions

> ⚠️ This is a CSS practice/recreation project for learning purposes. "Google" and the Google logo are trademarks of Google LLC — this project is not affiliated with or endorsed by Google.

## ✨ Features

- 🎨 Logo shape built using a single `div` with colored borders
- 🔵 The blue tail/bar created with a `::before` pseudo-element
- ⬛ The notch cut-out created with a `::after` pseudo-element (triangle trick)
- 🖤 Clean dark background for contrast

## 🔧 Built With

- **HTML5**
- **CSS3** — `border-radius`, pseudo-elements, positioning

## 💡 What I Practiced

- Creating shapes using only `border` colors and `border-radius`
- Using `::before` / `::after` pseudo-elements to add extra shapes without extra HTML
- The CSS "triangle trick" (transparent borders) to create a notch/cut-out effect
